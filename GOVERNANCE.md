# Governance

Finally is maintained by [@kaungzinye](https://github.com/kaungzinye).

## Decisions

Issues and pull requests are the public record for product and technical decisions. The maintainer weighs user impact, security, maintainability, privacy, and fit with the published roadmap. The maintainer has final responsibility for merges, releases, security advisories, and repository settings.

Small fixes can move directly through review. Large features start with an issue or specification so scope and data handling are clear before implementation.

## Contributors

Anyone may report bugs, propose features, improve documentation, review changes, or submit code. Sustained, useful participation may lead to additional repository access. Access is granted by the maintainer and can be removed when it is inactive or creates a security risk.

## Changes to governance

Governance changes use the same pull request process as code changes. The pull request must explain the practical effect on contributors and maintainers.
