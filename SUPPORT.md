# Support

Finally is maintained as an open-source project. Support is provided on a best-effort basis.

## Get help

1. Read the [README](README.md) and [setup guide](specs/001-notion-task-app/quickstart.md).
2. Search [existing issues](https://github.com/kaungzinye/finally/issues).
3. Open a [bug report](https://github.com/kaungzinye/finally/issues/new?template=bug_report.yml) for reproducible defects.
4. Open a [feature request](https://github.com/kaungzinye/finally/issues/new?template=feature_request.yml) for product ideas or general questions.

Include the app version or commit, iOS version, provider, expected result, actual result, and reproduction steps. Remove tokens, OAuth codes, server addresses that identify private systems, task content, and personal calendar information.

Security reports belong in the private channel described in [SECURITY.md](SECURITY.md).

The issue tracker does not provide emergency response, account recovery, or support for independent Notion, Vercel, Apple, Google, or Finally Server installations.
