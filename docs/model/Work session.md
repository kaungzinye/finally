# Work session

A timed block of work booked against a task and published to the calendar. It is how continuous work toward a distant deadline gets its notifications. It needs server mode.

A work session moves its task toward the [[Deadline]].

## Fields

- Start, end
- Task

## Rules

- The phone notifies when a work session starts.
- Moving a work session leaves the deadline alone. Finishing one leaves the task open.
