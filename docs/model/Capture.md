# Capture

The add bar. The user types a title and words that set its fields.

A capture with no project lands in the [[Inbox]].

Typing "fri" or "tomorrow" sets the [[Scheduled day]].

Typing "due fri" or "by fri" sets the [[Deadline]].

## Rules

- The Scheduled picker stops at the draft's deadline. A scheduled day typed past the deadline saves on the deadline day.
- Capture has no reminder picker. A deadline gets its defaults automatically.
