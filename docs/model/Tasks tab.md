# Tasks tab

The third tab, formerly Browse. Every task in the workspace, plus Settings behind the gear, search, and sort.

The Tasks tab opens with the [[Inbox]] and its count.

The Tasks tab groups the rest by [[Project]], three tasks each.

The Tasks tab offers an [[Unscheduled]] filter chip.

The Tasks tab switches between a list and the [[Board]].

## Rules

- The tab icon shows the Inbox count as a badge.
