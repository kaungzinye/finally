# Missed scheduled day

An open task whose scheduled day has passed. Nothing bad happened, so it carries no alarm.

## Rules

- It stays in [[Today]] in muted text reading "from Sat", never red.
- It sits in Other tasks on the Today tab. Swiping Reschedule on its row moves the scheduled day, which clears it.
- The evening [[Replanning]] prompt is where the user moves or drops it.
