# Replanning

The evening decision for each unfinished Daily Focus pick and each missed scheduled day: keep, break down, reschedule, defer, or drop.

Replanning closes out the day's [[Daily Focus]]. Today offers "Review the day" from 17:00, and all day while an earlier day's unfinished picks wait for replanning.

Replanning is where a [[Missed scheduled day]] gets moved or dropped.
