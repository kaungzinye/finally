# Today

Everything on the user's plate for the current day. Today is what's scheduled. Daily Focus is what the user will actually do.

Today holds every open task whose [[Scheduled day]] is today.

Today holds every open task whose [[Deadline]] is today.

Today keeps every [[Overdue]] task until it is finished or moved.

Today keeps every [[Missed scheduled day]] until it is replanned.

## Rules

- The Today tab, the Today widget, and the lock screen ring all read this one definition.
- Subtasks whose suggested date falls today or earlier count as scheduled today. A parent with open subtasks stays hidden behind them.
