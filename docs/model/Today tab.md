# Today tab

The first tab. It opens on what the user has to do today.

The Today tab leads with the [[Daily Focus]], headed "3 things to do".

Below the focus, the Today tab lists the rest of [[Today]] under "Other tasks", never repeating a focus pick.

## Rules

- Other tasks lists overdue tasks first in red, then tasks due today, then tasks scheduled today, then missed scheduled days in muted text.
- No sort or search buttons. Those live on Tasks.
- The add button never covers the last row.
