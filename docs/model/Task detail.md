# Task detail

The sheet that opens from any task row. It saves as the user types and closes with a swipe down. No Cancel or Save.

Task detail edits each [[Deadline reminder]] as a chip.

Task detail adds an [[Exact reminder]] through "Remind me at".

## Rules

- Status is one chip that cycles on each tap.
- Chips read "Scheduled" and "Deadline". The Scheduled picker stops at the deadline day.
- The "…" menu holds "Delete task", which asks first. Deleting takes the task out of every Daily Focus.
