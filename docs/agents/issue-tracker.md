# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI for tracker operations and infer the repository from the configured GitHub remote.

## Conventions

- Create a specification or issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- Apply or remove labels with `gh issue edit`.
- Close completed or rejected work with an explanatory comment.
- Apply `ready-for-agent` when a specification contains enough product, implementation, and testing direction for implementation planning.

## Pull requests as a triage surface

PRs as a request surface: no.

## Publication rule

When a skill says to publish to the issue tracker, create a GitHub issue in `kaungzinye/finally`.
