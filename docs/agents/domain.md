# Domain documentation

Engineering skills read `CONTEXT.md` before exploring this repository and use its glossary vocabulary in issues, specifications, tests, and implementation plans.

The repository uses a single-context layout:

- `CONTEXT.md` defines the product domain and ubiquitous language.
- `docs/adr/` contains architectural decisions when a choice needs durable rationale.

If an architectural decision conflicts with an existing ADR, surface the conflict explicitly instead of silently replacing the decision.
